# Study Alarm

Android app for study tracking and reminders: add subject, chapter, start and end time; get an alarm and a lock-screen notification at start time; total study hours are tracked automatically.

## Get the APK
Push to GitHub, open the **Actions** tab, run **Build APK**, then download **StudyAlarm-apk** from the finished run.

Or open the folder in Android Studio and use Build > Build APK(s).
